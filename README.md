# 🚀 TechNews Today - Desafio HTML & CSS

Página de notícias de tecnologia construída com HTML5 e CSS3, desenvolvida para o repositório **Desafio10_HTM-CSS**.



# 💻 Sobre o Projeto

O **TechNews Today** é uma landing page moderna com tema escuro (*dark mode*) dedicada a compartilhar novidades do mundo da tecnologia. 

# 🌟 Destaques do Layout
 **Notícia em Destaque**: Cartão principal com artigos em alta, como *"IA Revoluciona Desenvolvimento"*.
 **Mídia Integrada**: Seção *Tech em Vídeo* com exibição de conteúdo multimídia.
 **Formulário de Newsletter**: Área de inscrição com campos de e-mail, seleção de área de interesse (como *Inteligência Artificial*) e aceite dos termos de uso.



# 🛠️ Tecnologias Utilizadas

 **HTML5**: Estruturação semântica da página (`desafio10a.html`).
 **CSS3**: Estilização, esquemas de cores e layout (`10a_desafio.css`).
